Privacy Policy

Last updated: November 15, 2026

Purpose

MagicMirror Fitness Dashboard is a personal, non-commercial application used to display fitness, sleep, and recovery information.

Data Access

With authorization, the application accesses selected health and activity information from connected services, including Oura.

Data Storage

Retrieved health information is stored locally on the application owner's Raspberry Pi. Health data is not published to this website.

Data Sharing

The application does not sell or intentionally share personal health data with third parties.

Access and Deletion

The application owner controls local data storage and can delete stored data or revoke connected service authorization.

Contact

Privacy questions can be directed to the application owner using the contact information provided during application registration.
